# F2: ASR同级/更小替代选型

## Findings

### [1] Fun-ASR-Nano-2512 (800M) is Tongyi's 2025 LLM-based Chinese ASR successor path, covering zh/en/ja + 7 Chinese dialects and 26 regional accents, with AISHELL-1 CER 1.80 and AISHELL-2 CER 2.75
- quote: "Fun-ASR-Nano supports Chinese, English, Japanese, and Chinese dialects and accents... AIShell1 1.80 / AIShell2 2.75 / Fleurs-zh 2.56 / WenetSpeech Meeting 6.60"
- url: https://github.com/QwenAudio/Fun-ASR
- source_type: primary
- published: 2025-12 (checkpoint suffix 2512; arXiv:2509.12508)
- confidence: high

### [2] Fun-ASR-Nano architecture is SenseVoice encoder + Qwen3 decoder (800M), ships GGUF/llama.cpp runtime for CPU/edge, ModelScope checkpoint has native CTC timestamps, Hugging Face checkpoint initially lacked CTC tensors
- quote: "Fun-ASR-Nano (SenseVoice encoder + Qwen3 decoder)... The current ModelScope FunAudioLLM/Fun-ASR-Nano-2512 checkpoint includes all 86 trained ctc_decoder.* / ctc.* tensors and produces native CTC timestamps."
- url: https://raw.githubusercontent.com/modelscope/FunASR/main/docs/model_selection.md
- source_type: primary
- published: unknown (as of 2026 audit)
- confidence: high

### [3] Fun-ASR-Nano-2512 model card lists Apache-2.0 weights; production path includes vLLM batch (RTFx 340x vs 21x PyTorch) and WebSocket streaming SDK, but the current public release is not a pure offline 234M-class drop-in for SenseVoiceSmall
- quote: "The official Fun-ASR-Nano and Fun-ASR-MLT-Nano cards currently list Apache-2.0... PyTorch native RTFx 21x CER 8.06% | vLLM RTFx 340x CER 8.20%"
- url: https://github.com/QwenAudio/Fun-ASR
- source_type: primary
- published: 2025-12
- confidence: high

### [4] SenseVoiceSmall remains 234M, non-autoregressive, 5-language (zh/en/ja/ko/yue) with emotion+audio-event tags, ONNX/libtorch export, and official GGUF/llama.cpp runtime; it is not natively streaming (pseudo-streaming via third-party truncated attention)
- quote: "SenseVoiceSmall | ASR + emotion + events | zh/en/ja/ko/yue | 234M... streaming-sensevoice processes inference in chunks. To achieve pseudo-streaming, it employs a truncated attention mechanism, sacrificing some accuracy."
- url: https://github.com/FunAudioLLM/SenseVoice
- source_type: primary
- published: 2024-07 (paper) / maintained through 2026
- confidence: high

### [5] SenseVoiceSmall weights use FunASR Model Open Source License (commercial use clarified as permitted under section terms), not pure MIT; code is MIT
- quote: "Source code in this repository is licensed under the MIT License... Model weights are distributed separately and follow the terms on each model card... Commercial use of the official SenseVoiceSmall weights is permitted when the model license is followed."
- url: https://github.com/FunAudioLLM/SenseVoice
- source_type: primary
- published: 2026 (clarification comment referenced)
- confidence: high

### [6] Paraformer-zh (220M) remains FunASR's mature Mandarin production option with character-level timestamps, hotwords, and a dedicated streaming checkpoint (paraformer-zh-streaming); FunASR recommends it for Mandarin-only timestamp/hotword workloads
- quote: "Paraformer-zh | ASR + timestamps | zh/en | 220M... Paraformer-zh-streaming | Streaming ASR | zh/en | 220M... Switch to Paraformer when your workload is Mandarin-only and you want character-level timestamps or hotwords."
- url: https://raw.githubusercontent.com/modelscope/FunASR/main/README.md
- source_type: primary
- published: unknown (as of 2026 audit)
- confidence: high

### [7] icefall Zipformer Chinese models achieve AISHELL test CER 4.40% (73.4M encoder) / 4.67% (30.2M small) / 4.28% (157.3M large), and WenetSpeech streaming Zipformer (pruned_transducer_stateless5) reaches Test-Net CER 9.95% with modified beam search — strong small-size local options via sherpa-onnx
- quote: "Aishell Zipformer 73.4M dev 4.13 test 4.40; Zipformer-small 30.2M test 4.67; Zipformer-large 157.3M test 4.28... WenetSpeech streaming Test-Net 9.95 Test-Meeting 15.81"
- url: https://github.com/k2-fsa/icefall
- source_type: primary
- published: unknown (repo live as of 2026)
- confidence: high

### [8] FireRedASR2-AED (released 2026-02-12) is the strongest open Chinese industrial ASR under ~1B-class AED design: Mandarin avg CER 3.05, 19 dialect sets avg CER 11.67, word-level timestamps + confidence; outperforms Fun-ASR-Nano-2512 (Mandarin 4.55) and Qwen3-ASR-1.7B (3.76) on the same public suite
- quote: "Mandarin (4 test sets): 2.89% (LLM) / 3.05% (AED) average CER, outperforming Doubao-ASR (3.69%), Qwen3-ASR-1.7B (3.76%), Fun-ASR (4.16%) and Fun-ASR-Nano-2512 (4.55%)... FireRedASR2-AED also supports word-level timestamps and confidence scores."
- url: https://github.com/FireRedTeam/FireRedASR2S
- source_type: primary
- published: 2026-02-12
- confidence: high

### [9] FireRedASR2S packages ASR+VAD+LID+Punc as an all-in-one Linux-first stack; TensorRT-LLM accel claimed 12.7x on AISHELL-1, but README states only tested on Ubuntu 22.04 — Apple Silicon/MLX support is not established
- quote: "Benchmark on AISHELL-1 test set shows 12.7x speedup over PyTorch baseline (single H20)... FireRedASR2S code has only been tested on Linux Ubuntu 22.04. Behavior on other Linux distributions or Windows has not been tested."
- url: https://github.com/FireRedTeam/FireRedASR2S
- source_type: primary
- published: 2026-02-13 / 2026-03
- confidence: high

### [10] FireRedASR-AED-L (1.1B, 2025-01) already beat SenseVoice-Large and Paraformer-Large on public Mandarin benchmarks (avg-4 CER 3.18 vs 4.47 / 4.56), so the AED line is the practical ≤~1B accuracy upgrade path from VoxLab's current stack
- quote: "FireRedASR-AED 1.1B aishell1 0.55 aishell2 2.52 ws_net 4.88 ws_meeting 4.76 Average-4 3.18; SenseVoice-L 1.6B Average-4 4.47; Paraformer-Large 0.2B Average-4 4.56"
- url: https://github.com/FireRedTeam/FireRedASR
- source_type: primary
- published: 2025-01-24
- confidence: high

### [11] Distil-Whisper is English-only (166M/394M/756M) and explicitly not a Chinese option; multilingual recommendation is Whisper Turbo (809M) rather than distil checkpoints
- quote: "Distil-Whisper is only available for English speech recognition. For multilingual speech recognition, we recommend using the Whisper Turbo checkpoint"
- url: https://github.com/huggingface/distil-whisper
- source_type: primary
- published: 2023-11 (still current guidance)
- confidence: high

### [12] Moonshine Mandarin is MIT/ONNX-native and ultra-small (34M streaming, CER 16.1% no-space; 58M non-streaming Base CER 25.76%), far weaker than SenseVoice/Paraformer/Zipformer on Chinese — useful only if absolute size/latency dominates accuracy
- quote: "Mandarin | Tiny Streaming | 34 million | 16.1%† | MIT... Mandarin | Base | 58 million | 25.76% | Community... † No-space character error rate, not word error rate."
- url: https://moonshine-voice.readthedocs.io/en/latest/models/available-models/
- source_type: primary
- published: 2026 (docs current)
- confidence: high

### [13] whisper.cpp and mlx-whisper remain the best Apple Silicon Whisper runtimes (Metal/Core ML, quantization, VAD) but inherit Whisper's Chinese weakness; FunASR claims ~3x lower Chinese CER than whisper.cpp via its llama.cpp SenseVoice/Paraformer/Nano runtimes
- quote: "Run SenseVoice / Paraformer / Fun-ASR-Nano as a single self-contained binary... but with ~3× lower CER than whisper.cpp on Chinese." / "Apple Silicon first-class citizen - optimized via ARM NEON, Accelerate framework, Metal and Core ML"
- url: https://raw.githubusercontent.com/modelscope/FunASR/main/README.md
- source_type: primary
- published: unknown (runtime-llamacpp-v0.2.6 era)
- confidence: medium

### [14] Qwen3-ASR (1.7B) and GLM-ASR-Nano (1.5B) exceed the ≤1B budget; FireRedASR2 paper numbers show Qwen3-ASR-1.7B Mandarin avg CER 3.76 / dialect 11.85, worse than FireRedASR2-AED
- quote: "Qwen3-ASR | ASR, 52 languages | multilingual | 1.7B... GLM-ASR-Nano | ASR, 17 languages | multilingual | 1.5B"
- url: https://raw.githubusercontent.com/modelscope/FunASR/main/README.md
- source_type: primary
- published: unknown (as of 2026 audit)
- confidence: high
