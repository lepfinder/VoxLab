# F3: TTS现役模型官方版本与维护状态

## Findings

### [1] Kokoro 官方仍停留在 82M，无后续权重版本；推理库主分支最后提交为 2025-08-06，模型权重侧已基本停滞
- quote: "An inference library for Kokoro-82M. You can pip install kokoro."
- url: https://github.com/hexgrad/kokoro
- source_type: primary
- published: unknown (repo active through 2025-08-06)
- confidence: high

### [2] Kokoro 权重与代码均为 Apache-2.0；官方 README 明确支持中文（lang_code='z'）且依赖 misaki[zh]，但没有独立的官方中文改进权重
- quote: "🇨🇳 'z' => Mandarin Chinese: pip install misaki[zh]"
- url: https://github.com/hexgrad/kokoro
- source_type: primary
- published: unknown
- confidence: high

### [3] Kokoro 中文能力来自 G2P 库 misaki 的第二代中文分词器（借鉴 PaddleSpeech frontend），而不是新模型；misaki 本身也是 Apache-2.0
- quote: "The second gen Chinese tokenizer adapts better logic from paddlespeech's frontend. Jieba now cuts and tags, and pinyin-to-ipa is no longer used."
- url: https://github.com/hexgrad/misaki
- source_type: primary
- published: unknown
- confidence: high

### [4] Qwen3-TTS 于 2026-01-22 正式开源，目前公开的是 12Hz 系列 0.6B/1.7B，变体为 VoiceDesign / CustomVoice / Base；技术报告中的 25Hz 模型尚未公开放出
- quote: "2026.1.22: We have released Qwen3-TTS series (0.6B/1.7B) based on Qwen3-TTS-Tokenizer-12Hz."
- url: https://github.com/QwenLM/Qwen3-TTS
- source_type: primary
- published: 2026-01-22
- confidence: high

### [5] Qwen3-TTS 权重与代码均以 Apache 2.0 发布；官方技术报告（arXiv:2601.15621，2026-01-22）明确写明「we release both tokenizers and models under the Apache 2.0 license」
- quote: "To facilitate community research and development, we release both tokenizers and models under the Apache 2.0 license."
- url: https://arxiv.org/abs/2601.15621
- source_type: primary
- published: 2026-01-22
- confidence: high

### [6] Qwen3-TTS 官方侧重点是 CUDA + FlashAttention2 + vLLM-Omni，没有官方 MLX 端口；vLLM-Omni 目前仅支持离线推理，在线 serving 标注为「will be supported later」
- quote: "vLLM officially provides day-0 support for Qwen3-TTS! ... Now only offline inference is supported. Online serving will be supported later."
- url: https://github.com/QwenLM/Qwen3-TTS
- source_type: primary
- published: 2026-01-22 (news) / unknown (vLLM note)
- confidence: high

### [7] Qwen3-TTS 流式能力为 Dual-Track 混合流式，端到端首包延迟 97ms；qwen-tts 包最新为 0.1.1（2026-02-06），此后无新 PyPI 版本
- quote: "It can output the first audio packet immediately after a single character is input, with end-to-end synthesis latency as low as 97ms."
- url: https://pypi.org/project/qwen-tts/
- source_type: primary
- published: 2026-02-06
- confidence: high
